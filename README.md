# ETBVault

🚧 **Application en cours de développement.**

Suivi de prix des **Elite Trainer Box (ETB) Pokémon** (marché France) + coffre-fort personnel pour suivre ses plus-values / moins-values.

## Branches

- **`dev`** — branche d'intégration : tout le développement se passe ici.
- **`main`** — ligne de production : ne reçoit que les versions stables et déployables, taggées en SemVer (`v1.0.0`, `v2.0.0`, …).

> L'app n'est pas encore prête : le code vit sur `dev` en attendant la première release.
